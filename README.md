# M3UMaker
A simple CLI written in Python to make m3u files for your playlists.

It currently only works on Windows, with Linux support coming soon!

How to use:
When it prompts you, enter the absolute path to the folder that has your music files.
e.g. ```C:\Music\Is\Here```

Then when it prompts you again, enter the name you want for your playlist, preferably the name of the folder you entered last
e.g. ```Here```

Afterwards, a m3u file should be in the directory you gave the app.
